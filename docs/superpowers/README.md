# Design specs and implementation plans

These are the working documents that produced the two add-ons in this
repository. They are published unedited, as dated historical records, because
how the code was specified and planned is the subject of the talk these
materials accompany.

Read them as a snapshot of what was true on their date, not as current
documentation:

- They reference files that are not published here — the conference deck and
  its assets, the internal handoff document, a backup screencast. Those were
  real at the time and are simply not part of the public repository.
- Where a plan and the shipped code disagree, **the code is correct.** Several
  decisions changed during implementation, and the plans were not rewritten to
  match.
- Current documentation lives in `TA_anthropic/README.md`,
  `TA_openrouter/README.md`, and `TA_openrouter/docs/`.
